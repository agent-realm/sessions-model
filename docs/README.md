# Guides

Short guides to the two contracts. The contracts themselves ([sessions-model](../contracts/sessions-model.md)
and [sessions](../contracts/sessions.md)) are the authority; where a guide and a contract differ, the
contract wins.

| Guide | For |
|---|---|
| [Tutorial](tutorial.md) | a first record, from a transcript line to a valid session, in four steps |
| [Keys and identity](keys-and-identity.md) | anyone: how a session, a harness store and a record are named, and why they stay stable |
| [Implementing a session adapter](implementing-an-adapter.md) | someone writing a reader for a harness |
| [Consuming records](consuming-records.md) | someone storing, searching or summing the records |
| [Conformance](conformance.md) | someone claiming that an adapter or a consumer meets v1 |

The [examples](../examples/) show the records themselves, from one message to a full session.
